# Open Source Roadmap

## v0.1

- FastAPI + Jinja2 Dashboard。
- SQLite 数据库。
- GDELT、SEC EDGAR、RSS、NewsAPI、Alpha Vantage 适配器。
- 规则评分 + LLM JSON 修正。
- 企业微信推送。
- 基础测试、Docker 和文档。

## v0.2

- Alembic 数据库迁移。
- PostgreSQL 部署模板。
- 更完整的实体识别和 ticker/company 映射。
- API token、用户规则和事件订阅。

## v0.3

- embedding 聚类，支持 pgvector。
- 事件生命周期追踪和重大进展 diff。
- React Dashboard。
- Prometheus 指标、OpenTelemetry tracing。

## v1.0

- 多租户配置。
- 可插拔数据源 SDK。
- 多通道推送：Slack、飞书、邮件、Webhook。
- 稳定 schema 和插件协议。
